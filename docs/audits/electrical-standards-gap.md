## 3. What the redesign will fix (in simulator) and what it will not invent

**Fixes (in code, versioned in git — never via Admin per §32):**

- G2 EVSE C-curve variant + re-evaluate `pro-ev-charger-circuit` so it scores 100 under `uk`/`us`/`eu`.

- No full 3-phase phasor network solve, no 400 Hz, no per-clause `Cg/Ca/Ci` split, no 240 V split-phase socket — all remain backlogged and documented as teaching approximations. "NO THING IS HARD CODED" never applies to this section (§32) — super_admin stays **read-only**.
