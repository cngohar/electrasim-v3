# Fault Lab precise cues and Help proposal

Open `http://localhost:3004/docs/design/fault-lab-followup/index.html` while the
local review Vite is running (or use port 3000 with the regular dev server).

Compare three distinct representations of an open fault: component internal
conduction path, exact rendered-wire route, and a named terminal disconnection.
Wire position and tangent are sampled from the actual SVG path. One short
separation animation ends in a static gap; reduced motion shows the final state.
There are no repeated sparks, fire or invented damage. The scene is a conceptual
model diagram, not an inferred failure of a particular part inside a CFL driver.

The six-row Help dialog demonstrates numbered steps, small explanatory icons and
short titles. The applied catalogue card demonstrates visible status, duplicate
prevention, focus/details and Clear as a separate operation. All actions and
outcomes are illustrative; this page does not import a store, authorize a fault,
solve a circuit or implement the production fixes.
